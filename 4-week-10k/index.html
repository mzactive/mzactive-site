Four-week structure

Your training roadmap

Run four days per week. Keep easy sessions genuinely easy. All quality sessions include 10–15 minutes of easy warm-up and 10 minutes of cool-down.

WEEK 1
Establish
Run 1: 35 min easy + 4 × 20 sec relaxed strides, full easy recovery.
Run 2: 6 × 2 min controlled hard (RPE 7/10), 2 min easy jog between.
Run 3: 30 min easy.
Run 4: 50 min easy long run.
Strength: 2 × 20 min: squat, reverse lunge, calf raise, glute bridge, plank.
WEEK 2
Build
Run 1: 40 min easy + 4 × 20 sec strides.
Run 2: 5 × 3 min controlled hard (RPE 7/10), 2 min easy jog between.
Run 3: 30–35 min easy.
Run 4: 55 min easy long run.
Strength: 2 × 20 min; same exercises, controlled technique.
WEEK 3
Specific
Run 1: 40 min easy + 5 × 20 sec strides.
Run 2: 3 × 6 min at comfortably hard tempo effort (RPE 7/10), 3 min easy jog between.
Run 3: 30 min easy.
Run 4: 60 min easy long run.
Strength: 2 × 15–20 min; avoid training to failure.
WEEK 4
Freshen & assess
Run 1: 30 min easy + 4 × 20 sec strides.
Run 2: 4 × 2 min at controlled 10K effort (RPE 7/10), 2 min easy jog between.
Run 3: 25 min very easy.
Run 4: Rest 1–2 days, then complete a controlled 5K or 10K effort only if recovered; record time and perceived effort.
Strength: 1 light 15 min mobility/activation session.
Training rules

How to use the plan

  • Leave at least one easy or rest day between demanding sessions.
  • Easy running should allow full-sentence conversation (RPE 3–4/10).
  • Controlled hard work is strong but repeatable; do not sprint the intervals.
  • Stop if you experience sharp pain, chest pain, dizziness or unusual shortness of breath.
  • In hot conditions, reduce pace, choose cooler hours and hydrate appropriately.
  • If fatigue accumulates, remove the optional strides or shorten an easy run rather than forcing the session.
