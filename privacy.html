Privacy notice · إشعار الخصوصية

Marketplace intake is currently paused. The new marketplace API is configured not to accept provider registrations, profile edits, or booking requests. Do not submit personal details through the new marketplace while this notice is being reviewed.

استقبال البيانات عبر منصة السوق الجديدة متوقف حالياً. تم إعداد واجهة المنصة كي لا تقبل تسجيل المدربين أو تعديل الملفات أو طلبات الحجز. يرجى عدم إرسال معلومات شخصية عبر المنصة الجديدة إلى حين مراجعة هذا الإشعار.

What the marketplace is designed to process

When collection is deliberately enabled, the service is designed to process account email addresses and password hashes; Coach/Pacer profile details such as name, city, biography, languages, specialties, experience and indicative rate; and booking request details such as contact information, location, preferred date and goal. Passwords are not stored as readable text.

عند تفعيل استقبال البيانات، ستعالج المنصة بيانات الحساب والملف المهني ومعلومات طلب الحجز اللازمة للتواصل ومراجعة الخدمة. لا يتم حفظ كلمة المرور كنص مقروء.

Purpose and visibility

Profile data is intended to support provider account management and moderation. Only profiles approved by MZ Active are intended to appear in the public directory. Booking request details are intended for matching and responding to the request, and are visible to authorized administrators.

Service location and retention

The new API uses Cloudflare Workers and a separate D1 database configured in the APAC region. The exact retention period, deletion process and any cross-border processing details must be confirmed and documented before collection is enabled. The intake switch remains off until those details are reviewed.

Contact

For privacy questions, contact mzactive@yahoo.com. This page is an operational draft and requires review against applicable Qatar requirements before the marketplace accepts personal information.
