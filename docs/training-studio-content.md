# MZA Training Studio — MVP content policy
The 83-entry bilingual starter catalog is independently authored, consisting of common exercise names, original Arabic translations and short factual category/equipment tags. It contains no third-party images or videos and no default training prescription. Coaches choose the dose.
The existing saved-program workout library remains available as a separate feature. Custom exercises are stored in this browser, namespaced to the authenticated approved coach ID; they are not a cloud-synced or encrypted storage solution. Do not store confidential athlete information in custom exercise names.
External candidate: https://github.com/yuhonas/free-exercise-db declares the Unlicense in LICENSE.md; upstream image provenance requires independent verification. Another candidate is wger, whose initial exercise data is CC BY-SA 3.0 (https://wger.readthedocs.io/en/2.4/); individual media rights and attribution must be reviewed. No assets from that repository have been copied. Future media import requires documented creator, original source, license, attribution and commercial/derivative permissions per asset. No paid API.
The picker appends readable session text to the existing program editor and uses existing save/send endpoints. No backend migration or production deployment is needed to test this branch.

The expanded MVP includes copy/paste individual workouts and weeks, date-relative browser-local program templates, new-program reset, and an athlete weekly calendar with completion logs written through the existing authorized completion API. Templates exclude dedicated athlete identity fields, but free-text workout instructions may contain personal information; avoid adding it. Real browser mobile testing is simulated Chromium, not physical devices. No production deployment or full TrainHeroic feature parity is claimed.

Coach workspace: approved sports/bodybuilding coaches can open a dedicated full-width workspace at dashboard.html?studio=1, using the same authenticated data and existing editor. The legacy dashboard remains reachable and the workspace is opt-in pending production validation.
